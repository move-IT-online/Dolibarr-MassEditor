# Dolibarr-MassEditor
Produkte-Massen-Editor für Dolibarr

Installation:
1. per FTP ein neues Verzeichnis anlegen: /custom/massedit
2. in das neue Verzeichnis die index.php kopieren
3. über das Dolibarr-Frontend (Einstellungen -> Menüs -> Menü-Editor -> +-Zeichen) einen neuen Menüpunkt anlegen und die URL auf die neue Datei /custom/massedit/index.php
4. der neue Menüpunkt sollte dann in der oberen Navigationsleiste zu sehen sein
